# The Shift — Photography & Creation

A minimalist and immersive portfolio built with Next.js 14, SCSS Modules, and TypeScript.

## Overview

> A visual exploration of photography, textures, film grain, and experimental creation.  
> Shot in Paris, Tokyo, and London using Canon AE-1 and Ilford HP5 film.

This site showcases handcrafted visuals through a curated grid, animated scroll effects, and artistic navigation.  
Created with passion and a focus on storytelling, detail, and light.

## Stack

- **Next.js 14**
- **TypeScript**
- **SCSS Modules**
- **Framer Motion** for animations
- **Custom routing + dynamic slugs**
- **Markdown (.md) project files**
- **Fully responsive & dark mode ready**
